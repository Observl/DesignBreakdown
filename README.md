# DesignBreakdown · 拾形

将你感兴趣的网页设计拆解收藏。

## 交互原型

直接打开根目录 `index.html` 即可使用，无需安装或构建。也可以通过任意静态服务器运行。

- 拆解结果：网页示意预览、片段详情、定位、分类筛选、全选和批量收藏。
- 个人收藏库：搜索名称/标签/备注、按收藏夹与类型筛选、排序。
- 收藏管理：新建收藏夹、编辑备注、移动和移除收藏。
- 收藏数据使用 localStorage，仅保存在当前浏览器。
- 适配窄屏，支持键盘焦点与减少动画偏好。

## 当前边界

这是可交互原型，网页及片段均为原创演示素材。输入地址只演示拆解流程，不会访问或抓取目标网址。尚未接入账号、云同步、真实抓取、AI 识别、动效录制或代码提取。

## GitHub Pages

在仓库 Settings → Pages，将 Source 设为 Deploy from a branch，选择 main 和 /(root)，保存后可发布静态原型。以 GitHub 返回的发布地址为准。
